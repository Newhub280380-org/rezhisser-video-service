# Seedance prompts

31 Seedance video prompts copied from [seedance-ai-studio](https://github.com/Newhub280380/seedance-ai-studio) `index.html` (the `items` array).

[`seedance_prompts.json`](seedance_prompts.json) is a list of objects:

| Field | Meaning |
| --- | --- |
| `id` | Stable slug from the original card title, in source order. |
| `title` | Card title. |
| `prompt` | Prompt text. Most prompts expect a reference photo. |

The studio UI also groups these cards as fashion, 3D products, liquid and mosaic effects, cinematic, anime, UGC and social, reels, and film-meme mashups. That grouping is not stored in the JSON.
